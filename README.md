# WILSON HEALTH DATA ANALYSIS DASHBOARD

## Project Overview

This project is an interactive healthcare analytics dashboard built in Microsoft Excel to analyze hospital performance, patient demographics, medical conditions, revenue trends, and admission patterns.

The dashboard provides insights into patient distribution, billing performance, medication usage, hospital branch revenue, and treatment trends using dynamic charts, KPIs, and slicers.

---

## Objectives

The goal of this project was to:

- Analyze healthcare operational performance
- Monitor patient admission trends
- Identify the most common medical conditions
- Evaluate hospital revenue performance
- Explore demographic distribution of patients
- Build an interactive Excel dashboard for healthcare decision-making

---

## Dashboard KPIs

The dashboard tracks important healthcare metrics including:

- Total Customers: 766
- Total Revenue: £19.8M
- Average Admission Days: 7
- Average Billing Amount: £25,961.86
- Most Common Condition: Cancer
- Most Used Medication: Ibuprofen

---

## Key Insights

### Patient Analysis
- Cancer recorded the highest number of patients among all medical conditions.
- Female patients slightly outnumbered male patients.
- The 66+ age group represented a significant portion of admissions.

### Revenue Analysis
- Revenue fluctuated across the months with noticeable peaks during specific periods.
- Wilson Branch A generated the highest revenue among all hospital branches.

### Admission Trends
- Elective admissions were the most common admission type.
- Emergency and urgent admissions occurred less frequently.
